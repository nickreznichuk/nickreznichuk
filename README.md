### About me

I've been building production web, mobile and backend systems since 2019, end to end: database schema, APIs, React and React Native interfaces, and deployment on AWS.

Most of my recent work puts AI inside real products. I build tool-calling agents, MCP servers that let Claude Code and Cursor drive real workflows, RAG with evals in CI, and LLM moderation. I care about the production side of AI: evaluation, tracing, retries and cost control.

### Highlights

- **AI marketing automation agent.** Marketers describe a task in plain language, and the agent turns Figma mockups into finished, scheduled social posts (Figma and Hootsuite via MCP). Content prep went from **4–6 hours to 1.5 hours**.
- **Game asset platform + MCP server.** Batch generation, validation and API publishing of game artwork. Preparing 100 game cards went from **3–8 hours to ~10–20 minutes**, with batches of up to 1,000 images. A remote MCP server lets AI agents run the whole flow, with human approvals before anything goes live.
- **Social & talent platform** designed for up to **10M users** (100K pre-registrations at launch). LLM moderation of text and images, real-time chat, push notifications, web + React Native.
- **Telegram ecosystem** with **200K+ users** and ~10K DAU. A Telegram Web App with referrals, plus an internal analytics dashboard.
- **Codebase knowledge assistant.** Hybrid search with reranking over pgvector, a multi-step LangGraph.js agent with human approval, and an eval suite in CI.
